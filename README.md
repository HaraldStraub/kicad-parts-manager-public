# KiCad Parts Manager – Windows Beta

Local electronic component selection, library import and SPICE model assignment for KiCad.

The complete Windows beta package with its separate Release-DB will be available in [Releases](https://github.com/HaraldStraub/kicad-parts-manager-public/releases). Source-only Code ZIPs do not include the library database. Code: GPL-3.0-only; third-party libraries retain their own licenses.

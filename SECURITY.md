# Security

The server binds to 127.0.0.1 and is intended for one local user. Internet hosting, authentication and multi-user isolation are not provided.

Private vulnerability reporting is enabled: [report a vulnerability](https://github.com/HaraldStraub/kicad-parts-manager-public/security/advisories/new). Include affected version, reproduction steps, impact and a minimal redacted example. Do not include private databases, models or credentials in public Issues. No guaranteed response time during beta.

Browser SIM imports validate model directives and local dependencies. Command-line validation tools are for trusted local model files.

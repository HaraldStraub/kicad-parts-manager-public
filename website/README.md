# Project website

Live URL: https://haraldstraub.github.io/kicad-parts-manager-public/

Edit index.html for English page/guide content, base.css and style.css for appearance, site.js for dialogs, and assets/ for pictures. One HTML document maintains both the website and quick-start guide. You can edit files through GitHub's pencil button, commit through the web editor or use a local checkout. Keep an earlier commit available to revert unwanted changes.

The Pages workflow runs on main only when website files or the workflow change. Only website/ is uploaded as the Pages artifact; application code, databases, personal paths and maintenance outputs are excluded. Downloads point to the existing approved Windows Beta; no new application release is created.

To stop updates: disable the Publish website workflow in Actions. To take the site offline: use Settings → Pages → Unpublish site (if available), or delete Pages configuration through GitHub's supported Pages API/settings. Disabling a workflow alone does not remove the existing website. Do not delete the whole program repository. A later authorised deployment may republish the site. To remove website sources as well, delete website/ and its Pages workflow in a separate reviewed commit. Previous Git history remains unless separately removed.

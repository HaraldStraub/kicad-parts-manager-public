# Rückmeldung / Feedback

Über Rückmeldung auf Startseite, Katalog oder Import einen Fehlerbericht oder Verbesserungsvorschlag vorbereiten, prüfen und kopieren. GitHub öffnet ein vorausgefülltes Formular; erst dort selbst absenden. GitHub-Konto erforderlich. Öffentliche Issues sind öffentlich sichtbar; keine privaten Datenbanken, Modelle oder Zugangsdaten beifügen. Es gibt keine automatische Übermittlung oder zentrale Datenbank.

Bugs: https://github.com/HaraldStraub/kicad-parts-manager-public/issues/new?template=bug_report.md

Suggestions: https://github.com/HaraldStraub/kicad-parts-manager-public/issues/new?template=feature_request.md

Confidential security reports: see SECURITY.md; private vulnerability reporting is enabled. No new email address or Discussions service provided.
